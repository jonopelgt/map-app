# Map App

Version: 0.1.0 (major 0.x; minor builds increment lowest segment)

## Features
- Default map: Nashua, NH
- User location: blue dot
- Connection status page: OK (green) / Failed (red) title bar
- Session config: cert status + Verify button
- Stores certs for future use

## Build
Web version in /web. Open index.html.

For APK: import into Android Studio with WebView wrapping the web assets, or use Cordova/Capacitor.

## Dist
See /dist for packaged builds.
